# Data

Raw data are downloaded automatically and are not stored in this repository.

Run:

```bash
python 01_download_data.py
```

The script downloads the fixed 2020-2024 CURLEW_VLAANDEREN GPS release from Zenodo and the WorldClim 2.1 bioclimatic and elevation files used by the analysis.

Tracking data:
https://doi.org/10.5281/zenodo.15696532

WorldClim 2.1:
https://www.worldclim.org/data/worldclim21.html

The tracking data are released under CC0 1.0. WorldClim permits academic and other non-commercial use; redistribution or commercial use requires prior permission. The downloaded files remain under their source terms and are not covered by the repository's MIT licence.
